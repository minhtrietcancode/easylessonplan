This is a clone version of Cursor but used for teachers. This is a Flask web applications with 2 pages (currently): 
- Home Page 
- EasyLesson Page

The Home Page will have these features:
- A continue with google button, or Welcome, [User_first_name] if user used to logged in and then followed by a logout button in case user already logged in --> after successfully login then user would be directed to the easy lesson page. Once signed in, the systems will remember the logged in google account 
- The easy lesson page would have these features 
    + a model selecting button --> select a model amongs the supported models we defined 
    + a send messgae feature --> chat with a llm client
